Code index lookup, no model: who defines, calls, handles, publishes, or emits a symbol, in one call. MUST reach for this FIRST when tracing an event flow, a handler, a publisher, or the callers of a function across crates/contracts/packages, and before running more than one `grep` for the same symbol; `grep` is for text, `find` for behavior you cannot name.
`symbol`: one identifier (`CommitteeFinalized`, `CiphernodeSelector`, `CiphernodeSelector::handle`); several words (`decryption share aggregation`) run a ranked symbol search instead. Unknown names fall back to search. `Owner::name` limits definitions, callers, and references to files that define or mention `Owner`.
`path`: file or directory inside the working directory to restrict results to; omitted = whole workspace. `depth`: 1 (default) direct edges; 2–3 follow event chains (publisher → event → handlers → events they publish → their handlers) and caller chains.
Output: definitions, `Handled by` (Rust `impl Handler<…X…>` and match arms on a broad enum, including struct-variant arms), `Published by`, `Emitted by` (Solidity `emit`), callers, implementors, what the symbol calls/publishes, other references. For an actor: events it handles and publishes. Lines are `path:start-end  kind  name  — signature`; read returned ranges.
`Published by` lists struct literals and type/constructor heads sitting directly inside a `publish`/`send`/`do_send`/`emit`… call, through transparent wrappers (`TypedEvent::new(X { .. })`, `Box::new`, `.into()`). An event built into a variable first, or an enum variant passed as a field value, is not linked: when `Published by` is empty or short, `grep` for the name.
Cross-language edges, by name: a Solidity event shows `Decoded by` (the Rust decoder that matches its log), `Becomes` (the internal Rust type it turns into, via `impl From<Wrapper> for T`), and `Emitted by`; the internal type shows `Decoded from`; `impl From<A> for B` shows `Converts to`/`Converted from`; a Solidity function shows `Called from Rust` and a Rust function `Calls contract`; a Rust enum variant or string literal naming a Noir package (`ThresholdShareDecryption`, `"share_decryption"`) shows the `Circuit` (its `main`) and where Rust names it. At `depth` 2+ the event chain walks emitter → decoder → internal type → handlers → what they publish. For a whole multi-step question use `flow`.
Indexes Rust, TypeScript/JavaScript, Solidity, Python, Go, and Noir (`.nr`); refreshes incrementally on every call, so results match the working tree.
